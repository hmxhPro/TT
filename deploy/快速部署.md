# SOD 离线部署 · 极简执行清单

> 照抄即可。分两部分:**A. 源机打包** → **B. 目标机部署**。目标机全程无需联网。

---

## A. 源机打包(在已配好 SOD 环境的开发机执行)

```bash
# 1. 构建离线总包（产出 dist/sod-offline-bundle.tar，约 4.4G）
bash /home/hmxh/workspace/sodv3/SOD/deploy/package.sh

# 2. 传到目标服务器
scp /home/hmxh/workspace/sodv3/dist/sod-offline-bundle.tar 用户@目标IP:/data/
```

---

## B. 目标机部署(在目标服务器执行)

### B0. 前置确认(只看一次)

```bash
# GPU 驱动必须 R580+（CUDA 13.0 运行时要求）。看右上角 CUDA Version 是否 ≥ 13.0
nvidia-smi

# OpenCV 依赖的系统库（联网机可直接装；离线机用 .deb：sudo dpkg -i *.deb）
sudo apt install -y libgl1 libglib2.0-0
```

> 若 `nvidia-smi` 的 CUDA Version 是 12.x（驱动低于 R580），这套 cu130 环境用不了，
> 需在源机改用匹配的 CUDA 版本重建环境再打包（见本仓库 `部署文档.md` 附录）。

### B1. 解包并安装

```bash
cd /data
tar -xf sod-offline-bundle.tar
cd sod-offline-bundle

# 一键安装：解包环境/代码/权重 + 修正路径 + 生成配置
bash install.sh
```

### B2. 自检

```bash
bash verify.sh
# 关注 [3/8] GPU：必须 CUDA 可用。其余项应全绿。
```

### B3. 启动后端(端口 8000)

```bash
# 前台（实时看日志，Ctrl-C 停）
bash run_backend.sh

# 或 后台
nohup bash run_backend.sh > backend.out 2>&1 &
```

健康检查:
```bash
curl -s http://127.0.0.1:8000/readyz     # 期望含 "model":"ok" "gpu":"ok"
```

### B4. 启动前端(端口 8080,无需 nginx/node)

```bash
# 后端跑起来后再起前端
nohup ./env/bin/python serve_frontend.py > frontend.out 2>&1 &
```

浏览器访问:**`http://目标IP:8080/`**

## 可选:启用任务历史数据库(PostgreSQL)

```bash
# 前提：目标机已安装并启动 PostgreSQL（未启动先 sudo systemctl start postgresql）
cd /data/sod-offline-bundle/backend
bash scripts/init_postgres.sh      # 建库 + 写回 DATABASE_URL（需 sudo）
# 重启后端即自动建表
```

不配数据库也能正常检测,仅历史记录功能关闭。

## 停止服务

```bash
kill $(lsof -t -i:8000)     # 停后端
kill $(lsof -t -i:8080)     # 停前端
```

## 常见问题(一句话版)

| 现象 | 处理 |
|---|---|
| `verify.sh` GPU 不可用 / `torch.cuda.is_available()=False` | 驱动低于 R580,升级驱动或换 CUDA 12.x 环境重打包 |
| `ImportError: libGL.so.1` | `sudo apt install libgl1 libglib2.0-0` |
| `/readyz` 503 `model:"loading"` | 首次加载需数十秒,稍等;持续则看 `backend.out` 日志 |
| 检测框中文显示 `???` | 确认用 `run_backend.sh` 启动(它已设 `SOD_CJK_FONT`),勿裸跑 uvicorn |
| 前端能开但接口失败 | 用 `serve_frontend.py`(前端与 /api 同源),勿用 `npm run dev` |
| 上传时文件框看不到视频 | 视频必须在**开浏览器那台机器**上;远程访问时先把视频放到本机或可访问路径 |

## 一次性全量命令(目标机,复制粘贴版)

```bash
cd /data && tar -xf sod-offline-bundle.tar && cd sod-offline-bundle
sudo apt install -y libgl1 libglib2.0-0
bash install.sh
bash verify.sh
nohup bash run_backend.sh > backend.out 2>&1 &
sleep 20 && curl -s http://127.0.0.1:8000/readyz; echo
nohup ./env/bin/python serve_frontend.py > frontend.out 2>&1 &
echo "完成 → 浏览器访问 http://$(hostname -I | awk '{print $1}'):8080/"
```
